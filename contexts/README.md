# contexts 目录

存放**文档生成过程**的上下文：预期是什么、实际产出是什么、差在哪、为什么差。供后续改稿和 prompt 迭代用。

与 `docs/`（对外需求文档）、`log/`（技术底稿）、`Q&A/`（知识点）分工不同——这里记录的是**写文档时的意图与偏差**，不是平台现状分析。

## 文件索引

| 文件 | 用途 |
|------|------|
| [需求文档-差距与原因.md](需求文档-差距与原因.md) | `docs/大数据平台需求分析-v3.md` 与预期之间的偏差及生成原因 |
| [需求文档-我的预期.md](需求文档-我的预期.md) | **请你填写/修正**：对需求文档的定位、结构、详略、禁忌 |

## 使用说明

1. 先看「差距与原因」里已记录的条目；不对的在「我的预期」里改，或直接在差距文档「待确认」列补一句。
2. 改 v3 之前，建议先更新「我的预期」，避免同一类偏差重复出现。
3. 正式对外仍以 `docs/大数据平台需求分析-v3.md` 为准，本目录不替代需求正文。
