## 九、问题归纳

### 9.1 高频问题类型

1. **存储与硬件**：HCI 磁盘损坏/卡慢、磁盘拔插频繁
2. **数据链路**：数据湖拉取失败、新中间表无数据/异常/延迟
3. **任务稳定性**：任务全部暂停、长时间无结果
4. **资源与运维**：OOM、审计日志丢失、日志压缩停止

### 9.2 影响面

- **内部**：误漏报运营、任务分析
- **外部**：AES 银狐样本狩猎、北研监管支撑

### 9.3 运维成本

- 人力：129h 总投入，核心维护人员 60% 工作时间绑定平台
- 应急手段以重启、重试、删数据、删任务为主，根因治理与数据湖迁移需持续推进

### 9.4 战略方向

- 短期：补齐新需求（IP 热度、运营 Agent 查询），稳定中间表与日志压缩链路
- 中期：联合数据湖迁移（6/18 提需求 → 6/30 节点），任务类分析拆表
- 长期：抽离活跃度/趋势类任务为独立业务流程，平台定位为多部门共用数据源
