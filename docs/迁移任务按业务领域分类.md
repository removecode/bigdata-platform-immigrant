## 分类口径

按任务主要支撑的业务结果归类，主要依据原始任务材料中的用途描述，SQL用于辅助确认加工行为。判断路径为：明确用途 → 实际产出 → 产出使用者 → 验收人。目前实际读取者、业务负责人及验收人尚未全部核实。

每个任务暂设一个主类别，便于去重统计；一个任务可以服务多个业务，后续允许补充次级标签。本分类不替代“接入/加工/消费”技术职责分类，也不替代原始表/压缩表/中间表/基础表依赖标签，不直接决定迁移顺序或任务去留。

45项为盘点全集，包含历史已下线、可下线和待确认任务，不等于45项都需要迁移。具体去留以业务确认和决策追踪为准。

45项来自《大数据平台YARN上的任务梳理-云脑大数据平台.csv》的服务/任务名称去重：同一服务下的多条SQL和子任务合并计1项，去除名称中的星号及末尾`(oozie)`等展示标记，不计汇总行。DataX内部同步脚本不在这里逐个展开计数，不能把表数或SQL片段数当作任务数。

原材料状态快照为：保留31项、待确认9项、可下线2项、已下线3项，合计45项；这是历史材料状态，不是最新业务确认结果。2026-09-15用户确认`phishing-url-operation-prc`下线，现标记为“已确认下线，待实施”（DEC-004），不再作为待确认迁移候选。任务仍保留在45项盘点清单中以追踪退出。
