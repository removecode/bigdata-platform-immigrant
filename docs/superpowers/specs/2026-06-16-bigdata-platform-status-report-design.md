# 大数据平台现状汇报 Markdown 设计说明

日期：2026-06-16

## 目标

生成一份用于领导汇报的 Markdown 底稿，后续可转 PPT、飞书文档或 XMind。文档以截图中的脑图框架为主，填充已有历史材料，不在本版展开整改方案。

## 范围

本版只覆盖：

- 两条核心数据流：
  - 审计日志链路：审计日志 -> 原始日志表 -> 日志压缩表 -> 旧中间表。
  - 产品日志 / 数据湖链路：产品日志（数据湖） -> 原始数据表 -> 新中间表。
- 当前承载业务：
  - 对外业务。
  - 内部生产。
  - 运营业务。
- 历史问题记录：
  - 保留详细问题表。
  - 增加简要问题归类。
- 后续新增需求分类：
  - 运营查询类。
  - 情报分析类。
  - 监管与运营支撑类。

本版暂不展开：

- 整改方案。
- 负责人。
- 排期。
- 验收标准。
- 监控 SLA。

## 内容来源

- `outputs/大数据平台关键数据流系统分析临时文档.md`
- `outputs/大数据平台运营需求原始诉求分析临时文档.md`
- `outputs/大数据平台历史问题记录临时文档.md`
- 用户提供的 XMind 截图框架。

## 结构设计

1. 汇报摘要。
2. 当前大数据平台数据流。
3. 当前承载业务。
4. 历史问题记录。
5. 后续新增需求分类。
6. 本版暂不展开内容。

## 自检

- 无 TBD / TODO。
- 当前业务与后续新增需求分开。
- 数据流只保留审计日志链路、产品日志 / 数据湖链路。
- 历史问题记录保留详细字段。
- 不包含整改方案、负责人、排期和验收标准。
