# 流程里有没有真正的文件压缩

**问：** 实际上没有压缩，只是业务定制处理？

## 答

**基本正确。**

| 说法 | 是否成立 |
|------|---------|
| 没有 zip/gzip 独立压缩步骤 | ✅ 文档未记载 |
| `log_compress` = 明细日志汇总入宽表 | ✅ |
| 各 Oozie 任务 = 定制 ETL | ✅ |
| 完全没有体积优化 | ⚠️ Parquet 格式本身可能压缩 |

### 更准确表述

平台核心是**按业务规则做分层 ETL**；`log_compress` 任务名里的「压缩」= **数据汇总提炼**（类似 SQL `GROUP BY` 聚合），不是文件压缩。

向同事描述时建议说「审计日志 ETL / 汇总入 DWB」，避免被理解成 gzip。
