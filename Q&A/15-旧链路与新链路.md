# 哪些是旧链路、哪些是新链路

**问：** 旧链路和新链路怎么分？

## 答

### 对照表

| | 旧链路 | 新链路 |
|--|--------|--------|
| **数据来源** | Kafka → `log_audit_source` / `log_stats_source` | ClickHouse SODL |
| **核心任务** | `log_compress` | `sodl_ods_info_new` + `sodl_dwb_info` |
| **ODS** | `csc.ods_csc_log_audit` / `stats` | `sodl.*` |
| **DWB（中间表）** | `default.dwb_*_info` | `sodl.dwb_sodl_*_info` |
| **汇报叫法** | 审计日志链路 | 产品日志/数据湖链路 |

> 来源：`log/DATA_FLOW.md` L29–42；`docs/...status-report-design.md` L13–15

### 新链路

```text
ClickHouse → sodl_ods_info_new → sodl.* ODS
  → sodl_dwb_info → sodl.dwb_sodl_md5/domain/ip_info
```

### 旧链路

```text
Kafka → log_audit_source → log_compress
  → csc.ods_csc_log_audit → audit DWB → merge → default.dwb_*_info
```

旧链路中 `dw_md5_info` 等 4 个多源 DW 任务**已注释**，现行只走 audit 路径。

> 来源：`log/DATA_FLOW.md` L125–126、L277–280

### 共用与独立

- **共用**：`create_hive_partition`、威胁情报维表、`topthreat_hot_stat`（混合输入）
- **独立**：`secevent_analyse`（FLKF，Spark）

> 来源：`log/DATA_FLOW.md` L163–175、L221–227
