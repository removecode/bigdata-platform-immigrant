# 要了解平台需要掌握什么

**问：** 需要知道什么背景和流程？

## 答

### 平台是什么

基于 **Oozie** 调度的大数据**安全日志处理**平台，覆盖深圳（ShenZhen）和法兰克福（FLKF），共 **6 个 Coordinator 任务**。

> 来源：`log/DATA_FLOW.md` L5–7

### 两条核心数据流

**新链路（SODL 数据湖）**

```text
ClickHouse SODL → sodl_ods_info_new → Hive ODS (sodl.*)
  → sodl_dwb_info → sodl.dwb_sodl_* → topthreat_hot_stat → MongoDB
```

**旧链路（审计日志）**

```text
Kafka → log_audit_source / log_stats_source → log_compress
  → csc.ods_csc_log_audit/stats → default.dwb_*_info
```

> 来源：`log/DATA_FLOW.md` L13–42；`outputs/...系统分析临时文档.md` L25–40
