# 还有哪些重要概念

**问：** 除背景与流程外还要懂什么？

## 答

### 数据分层与指标

| 概念 | 说明 |
|------|------|
| ODS | 原始/近原始入湖层 |
| DWB | 按威胁指标聚合的宽表 |
| 四类指标 | MD5、域名、IP、URL |
| `src_log` | DWB 记录标记来自哪张 ODS 表 |
| `attack_count` | 攻击次数；`sip_iocstat_log` 用 `sum(record_count)` |

> 来源：`log/ODS_TO_DWB_DETAIL.md` L234–245、L61–66

### 威胁情报与过滤

- 黑 DNS / 黑 IP / URL 信誉库、`sri.ods_sri_ti_tags`、设备画像维表
- `domain_info` 是**窄表**：只保留黑域名或顶级域名，非全量域名日志

> 来源：`log/ODS_TO_DWB_DETAIL.md` L100–102；`log/DATA_FLOW.md` L236–247

### 调度与分区

- Oozie Workflow（DAG）+ Coordinator（cron）
- `create_hive_partition`：T+2 预建分区
- `topthreat_hot_stat`：T-2 小时数据偏移

> 来源：`log/README.md` L7–13；`log/DATA_FLOW.md` L186–194、L167

### 平台生态

- 约 50 个下游业务服务 + 23 条运营手工查询诉求
- `topthreat` 的 domain/url 混合旧日志与 SODL，file 仅来自 `log_audit_source`

> 来源：`outputs/app-call-graph匹配统计临时文档.md`；`outputs/...系统分析临时文档.md` L256
